# JavaScript - Top 50 High-Priority Interview Questions

Based on the JavaScript topics covered so far: **Data Types, Primitive vs Non-Primitive, Arrays, Strings, Functions, Loops, Type Coercion, Objects, Set, Map, and basic coding problems.**

1. What is the difference between **primitive and non-primitive data types** in JavaScript?
2. What are the different **data types** in JavaScript?
3. What is the difference between **`let`, `const`, and `var`**?
4. What is **type coercion** in JavaScript?
5. What is the difference between **`==` and `===`**?
6. What is the difference between **String Literal and String Object**?
7. What is the difference between **Array and Object**?
8. How do you **declare and initialize an array** in JavaScript?
9. How do you **access an array element**?
10. What is the difference between **array length and array index**?
11. How do you find the **last element of an array**?
12. What is the difference between **`push()` and `unshift()`**?
13. What is the difference between **`pop()` and `shift()`**?
14. What is the difference between **`slice()` and `splice()`**?
15. Does `slice()` modify the original array?
16. Does `splice()` modify the original array?
17. How do you **sort numbers in ascending and descending order**?
18. Why does `sort()` behave unexpectedly with numbers?
19. How do you **iterate through an array**?
20. What is the difference between **`for`, `for...of`, and `forEach()`**?
